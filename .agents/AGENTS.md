# Project Rules

- **Strict User Scope Constraint**: Siga RESTRITAMENTE apenas o que for solicitado pelo usuário. NUNCA altere a largura dos elementos, layouts existentes, dimensões de cartões/botões ou estilos de interface que não tenham sido explicitamente pedidos para serem modificados. Só invente ou faça alterações adicionais se o usuário pedir expressamente.
- **Auto-push e Deploy no GitHub**: Sempre que realizar alterações no código a pedido do usuário, faça automaticamente o commit e push para o repositório GitHub (`git add .`, `git commit -m "..."`, `git push`) e publique a versão atualizada no GitHub Pages rodando o deploy (`cmd /c "npm run deploy"`).
